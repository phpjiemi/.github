# 🔓 php.jiemi.xyz

[php.jiemi.xyz](https://php.jiemi.xyz) is a PHP decoding service that helps developers process files protected by common PHP encoders and review or download the resulting files.

## 🧩 Supported Decoders

| Decoder | Supported Format |
| --- | --- |
| 🔐 **ionCube Decoder** | PHP files encoded with ionCube |
| 🛡️ **SourceGuardian Decoder** | PHP files encoded with SourceGuardian |
| ⚙️ **Swoole Decoder** | Swoole-related encoded PHP files |
| 📦 **XLoad Decoder** | PHP files encoded with XLoad |

## 🚀 How to Use

1. 📤 Submit a file at [php.jiemi.xyz](https://php.jiemi.xyz).
2. 🎯 Select the matching encoder and start the decoding process.
3. 📥 Review or download the output files.

Decoded files may need to be checked and tested in the context of your project.

## ⚠️ Usage Notice

Only submit code that you own or are authorized to process. Use and distribution of decoded files must comply with the original software's license terms and applicable laws.
